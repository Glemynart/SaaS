# Claude Skills del Proyecto

## Objetivo

Este proyecto versiona un conjunto de Claude Skills para mantener un entorno de desarrollo consistente entre todos los colaboradores y agentes de IA.

Estas skills son herramientas de desarrollo.

No forman parte del producto desplegado.

---

## Fuentes

Las skills provienen de:

- Anthropic Skills
- ECC
- Owl Designer
- Impeccable
- Taste Skill
- UI/UX Pro Max

---

## Organización

### Diseño

Utilizadas para:

- UX
- UI
- Design System
- Arquitectura de información
- Accesibilidad
- Investigación de usuarios

### Arquitectura

Utilizadas para:

- Diseño de APIs
- Planificación
- Investigación
- Revisión técnica

### Backend

Utilizadas para:

- NestJS
- Prisma
- PostgreSQL
- Migraciones
- Patrones

### Calidad

Utilizadas para:

- Auditorías
- Seguridad
- Verificación
- TDD

---

## Versionado

Las skills se versionan junto con el proyecto para garantizar un entorno reproducible y consistente.

Las configuraciones personales (por ejemplo `.claude/launch.json`) no forman parte del repositorio.
