# Product Requirements Document

## Nombre del Producto

Plataforma SaaS de Gestión Administrativa para Operadores Educativos y Contratistas.

## Visión

Simplificar la gestión de contratos, expedientes, alertas y facturación electrónica mediante una plataforma moderna, fácil de usar y enfocada en procesos operativos.

## Problema

Las organizaciones gestionan información mediante Excel, documentos Word y múltiples herramientas desconectadas.

## Objetivos

- Reducir trabajo manual.
- Automatizar contratos.
- Centralizar expedientes.
- Gestionar alertas.
- Emitir facturación electrónica.

## MVP

### Módulo Empleados

- CRUD
- Importación Excel
- Búsqueda

### Módulo Contratos

- Plantillas DOCX
- Contratos individuales
- Contratos masivos
- PDF

### Módulo Expediente

- Subida de archivos
- Organización documental

### Módulo Alertas

- Vencimientos
- Notificaciones

### Módulo Facturación

- Clientes
- Productos
- Facturas
- Notas crédito
- Notas débito
- Matías API

## Usuarios

- Administrador
- Operador

## Restricciones

- No desarrollar contabilidad.
- No desarrollar ERP.
- No desarrollar nómina completa en MVP.

## Métricas de Éxito

- Primer cliente piloto.
- Primer cliente de pago.
- Contratos generados.
- Facturas emitidas.
- Usuarios activos.
